# v1.3.4

功能版：DeepSeek Harness 卡片新增「一键启动dsh web」按钮，纯本地链路一键拉起并打开 dsh Web UI，无需配置 Tailscale 远程访问。

## Features

- **一键启动dsh web**：「一键启动远程访问」左侧新增同级主按钮，点击后自动确保 dsh web 在本地运行并用系统浏览器打开 `http://127.0.0.1:3899`——未安装 dsh 时先经 `npm install -g @deepseek-ai/dsh` 自动安装，已在运行则直接打开（幂等，等同于「打开 dsh Web」）。纯本地链路，不触碰 Tailscale / 回环反代 / serve 配置；3899 被无关进程占用时明确报错「端口 3899 被其他进程占用」，不会把浏览器打开到错误服务；启动失败带 `~/.dsh/dsh-web.log` 日志诊断
