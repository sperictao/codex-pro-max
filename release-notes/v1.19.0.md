# v1.19.0

## Features

- **Guard: remove written config**: parameters that are disabled and unlocked
  now offer a "Remove Config" action that deletes the parameter's value from
  the target `~/.codex/` file while keeping the guard entry itself. All apply
  modes are covered: TOML keys are removed with structure-preserving edits,
  files managed by `file_overwrite` are deleted, and managed markdown blocks
  (including the trailing newline) are stripped. A backup is written to
  `~/.codex/dashi-backups/` before anything is removed, and a bilingual
  confirmation dialog states exactly what will happen before the deletion.
- **Boolean toggles write explicit values**: the guard checkbox now sends the
  target boolean directly instead of negating a value fetched from a fresh
  view, eliminating a stale-view race between refresh and toggle. Locked
  parameters still short-circuit before any write.

## Fixes

- `scripts/test-theme.mjs` still compiled `src/theme.ts`, which had moved to
  `src/shared/theme.ts` in the `shared/`-consolidation refactor; the theme
  smoke test now resolves the new path and passes again under `pnpm test`.
