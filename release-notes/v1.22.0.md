# v1.22.0

## Changes

- **Command palette (Cmd/Ctrl+K)** — a new palette, also reachable from the
  header search button, fuzzy-finds and jumps straight to any view, settings
  section, or global action: check for updates, open the repository, open the
  log directory, toggle light/dark. Its command list is generated from the same
  navigation source as the header and the settings sidebar, so the three can no
  longer drift apart.
- **Shell UI rebuilt on an in-repo component primitive layer** — buttons,
  inputs, selects, switches, cards, badges, dialogs, tooltips and menus now come
  from vendored shadcn `radix-nova` primitives instead of a shared bag of
  Tailwind class-string constants (`src/shared/lib/ui.ts`, removed; ~85 call
  sites across 12 views migrated). Visible results:
  - switches are actually visible and animated — the previous build shipped a
    transparent switch track (see Verification),
  - dialogs gain a focus trap, scroll lock, Escape-to-close and focus restore,
    with a 10% blurred scrim instead of a heavy grey one,
  - destructive row actions (delete provider / preset / guard file / custom
    parameter) moved into a `⋯` menu; primary actions stay inline,
  - guard parameter help uses a real tooltip instead of a hand-rolled
    absolutely-positioned card, and per-row actions are always visible rather
    than revealed on hover (hover-only controls were keyboard-unreachable),
  - elevation follows the theme: floating surfaces use a 1px ring tinted from
    the foreground token plus the theme's own shadow ladder, so all 42 theme
    families now drive shadows as well.
- **Toasts moved to `sonner`** — same bottom-right placement and the same
  3.3 s lifetime as before; type colours map onto the existing status tokens.
- **Dead code from the `dsh` module removal (`e7bc945`) cleaned up** — about
  80 lines of unused timeline CSS, the smoke fixtures and `dsh_*` commands, and
  102 unused Rust i18n strings.

- `pnpm test` — the `check-craft` conformance gate, 5 theme tests and 22
  vitest tests.
- `pnpm exec tsc --noEmit` and `pnpm build` — clean.
- `cargo test` — 52 passed / 0 failed; `cargo clippy -- -D warnings` — clean.
- Before/after screenshots taken by running the same smoke suite against a clean
  `HEAD` worktree.
- GitHub Actions `Quality` (frontend + rust) green on the merged commits.
- `node scripts/check-release.mjs --tag v1.22.0` passes.

## Upgrade notes

- No migration needed: the theme family, theme mode and language still live
  under the same `localStorage` keys, and `LauncherConfig` is unchanged.
- The guard screen no longer hides per-parameter actions until you hover, and
  `Delete` now sits behind the `⋯` button — nothing was removed, only moved.
- Dialogs now close on `Escape` when they have a cancel path; previously the
  key was ignored.
