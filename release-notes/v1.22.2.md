# v1.22.2

## Changes

- **Windows Codex process detection hardened** — desktop Codex is now recognized across OpenAI/Codex, Programs/Codex, Program Files/Codex, Microsoft WindowsApps aliases, and MSIX package paths while continuing to exclude the npm Codex CLI executable.
- **Longer Windows CDP startup grace period** — Windows now waits up to 30 seconds for the Codex CDP port to become ready; macOS and Linux keep the existing 15-second window.
- **CDP timeout now falls back to the existing restart flow** — after the wait expires on Windows, the launcher re-checks for a running Codex desktop process. If Codex is running without the CDP port, it returns the existing `CODEX_RUNNING_NO_CDP|` marker so the UI can close and restart Codex with the required debugging arguments instead of reporting a generic timeout.
- **Regression coverage added** — tests cover supported Windows desktop installation paths plus an npm CLI path that must not be treated as the desktop app.
