# v1.1.1

v1.1.0 的修复版：Windows 控制台窗口闪烁回归 + dsh 更新按钮显示修复，以及集成页两处布局微调。

## Fixes

- **Windows 控制台窗口闪烁**：dsh 模块的 `which()`（`cmd /c where`，每次 dsh 检测调用 4–6 次）与 `kill_by_pattern()`（powershell，每次停止/更新重启触发）漏带 `CREATE_NO_WINDOW`，每次调用都会闪一个终端窗口——v0.2.1 已修过同一问题，dsh 模块新增时回归，本次补齐
- **dsh 更新按钮恒显**：按钮同时带 `hidden` 与 `inline-flex` 类，Tailwind utilities 层里 `.inline-flex` 排在 `.hidden` 之后，类方式永远隐藏不掉，无更新时显示为一个空的黑/深色胶囊；改用 `hidden` 属性（preflight 的 `display:none!important`）可靠隐藏

## Features（布局调整）

- **dsh 更新按钮移至版本号胶囊右侧**：头部右侧顺序为 版本号 → 更新按钮，样式改为紧凑药丸按钮
- **URL 胶囊与打开按钮移至操作行右侧**：头部只保留版本号与更新按钮；操作行为 一键启动 / 停止（左）· 打开 / URL 胶囊（右）

## 发布

- 版本号同步至 1.1.1（package.json / Cargo.toml / tauri.conf.json / Cargo.lock）
