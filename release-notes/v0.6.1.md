# v0.6.1

修复 Windows 上 Codex 应用路径无法识别的问题，并支持没有应用执行别名的微软商店版 Codex/ChatGPT。

## Bug Fixes

- 修复 Windows 设置页「浏览」选不中 Codex：改用文件选择器（过滤 .exe），不再复用只认 .app 包的目录选择器
- 修复 Codex 自动探测漏检：补齐直装版真实安装位置（`%LOCALAPPDATA%\OpenAI\Codex\bin` 等）、机器级 `Program Files`，并扫描安装目录命名差异兜底

## New Features

- 支持微软商店版（MSIX）Codex/ChatGPT：无应用执行别名也能识别，通过 appmodel API 探测已安装包族，经 `IApplicationActivationManager` 激活并把 `--remote-debugging-port` 透传到应用命令行（方案参考 CodexPlusPlus）
- 商店版别名目录扫描兜底，覆盖别名命名差异
