# v0.12.2

## Internals

本版本为纯重构发布，无功能与行为变化：

- **Rust**：`codex_guard.rs`（1376 行单文件）拆分为 10 个职责单一的模块（toml_ops / markdown_block / schema / validate / backup / files / engine / view / poll / commands），对外接口不变
- **前端**：`main.ts`（1823 行单文件）拆分为 8 个 ES 模块（state / nav / core / service / guard / fastctx / updater / shell），入口仅剩 4 行；模块依赖单向，跨域通信集中在事件接线（ADR 0009）
- **CI**：质量门新增 `cargo test`，31 个 Rust 单元测试纳入防线（新增 5 个关键路径测试：TOML 比对、markdown 区块边界）
