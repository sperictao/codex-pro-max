# v0.14.0

## Features

- **内置 Taskboard 升级到 v1.0.3（上游 origin/main）**：合并 dashi-taskboard 上游大量更新，包括自托管 Jira 集成（看板内直接聚焦 Jira 任务）、附件在 Finder 中显示、项目标签持久化与删除、嵌入式附件打开、看板卡片可点击、微调 Jira 同步身份安全、以及 Windows 桌面构建管线
- **taskctl 端点发现双轨兜底**：合并后的 `taskctl` 同时支持外部 launcher 发布的用户级运行时端点（`~/.dashi-taskboard-launcher/launcher-runtime.json`）与上游自带的 vendor 内 `.data` 端点，并保留 `--runtime-file` 显式指定能力

## Fixes

- **打包不再漏掉 `cli/taskctl.mjs`**：`tauri.conf.json` bundle resources 补齐 `vendor/dashi-taskboard/cli`，避免安装包内 taskctl 停留在旧版、忽略运行时端点文件而撞上 token 模式服务的 `404 Route not found`（本机实机复现并验证修复）
