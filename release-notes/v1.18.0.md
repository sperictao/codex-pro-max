# v1.18.0

## Features

- **Vendored taskboard updated to upstream v1.1.21–v1.1.22**: merge 37 upstream
  commits into `vendor/dashi-taskboard` while preserving the launcher runtime
  endpoint discovery (`~/.codex-pro-max/launcher-runtime.json`) and the
  injector reliability fixes. Highlights:
  - **Windows native activation**: packaged Codex now launches through the
    Windows activation module instead of a raw process spawn, so Store/MSIX
    installations start reliably and the injector profile path is
    normalized. The activation module is bundled with the launcher.
  - **Windows injector reliability**: the injector hides the console window on
    Windows, includes the activation module in the app bundle, and stabilizes
    the Codex launch retry loop instead of spinning.
  - **Beta release channel**: the native app name and updater channel now
    surface the beta channel, with app-name migration preserved across
    updates.
  - Board UX fixes: project menu height limit raised, detail checklist
    checkboxes optically aligned, and the caret is placed after uploaded
    media. New issues reuse inline media attachments instead of duplicating
    them.
  - Release/CI: verified release promotion environment, upload caret fix,
    and a protected release promotion workflow.

## Verification

- Taskboard suite: `node --test` 388 tests, 387 passed / 0 failed
  (1 platform-skipped); `npm run typecheck` passes; `build:web` rebuilds
  `dist/web` cleanly.
- The injector merge keeps the fork's page-recognition helpers
  (`isChatGptDesktopPage` / `isCodexPageTarget` / `isExcludedCodexRoute`)
  and adopts upstream's `windows-codex.mjs` module for Windows process
  inspection and activation; `cli/taskctl.mjs` keeps
  `defaultLauncherRuntimeFile` for launcher endpoint discovery.
- `pnpm run check:release -- --tag v1.18.0` passes.
