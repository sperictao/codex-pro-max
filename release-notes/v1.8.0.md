# v1.8.0

DeepSeek Harness（dsh）模块交互重构：访问模式切换 + 一键启停按钮对齐主页风格；修复 `pnpm tauri dev` 在 GUI 环境 PATH 缺 cargo 时无法启动的问题。

## Features

- **dsh 访问模式切换**：远程访问开关改为纯模式选择（本地访问 / 远程访问），切换不再自动执行启用或停用；按当前模式显示对应的安装进度时间轴（本地 4 步 / 远程 8 步）
- **按模式一键启停**：一键启动/关闭按钮移到模式下放，启动按当前模式走对应流程（本地 `dsh_start_web` / 远程 `dsh_setup`），关闭统一走 `dsh_stop`
- **双模式 URL 胶囊**：本地模式显示 `http://127.0.0.1:3899`，远程模式显示 `https://<hostname>.ts.net`，均带复制 / 打开按钮
- **一键启停按钮对齐主页风格**：关闭按钮改为主页 Stop All 同款危险色，与启动按钮同尺寸；启动/停止独立 busy 状态并切换 `Starting...` / `Stopping...` 文字；按 dsh 运行状态自动禁用对应按钮

## Fixes

- **`pnpm tauri dev` 启动失败**：Rust 工具链装在 `~/.cargo/bin`（rustup 默认）但 GUI 环境 PATH 不含它，导致 `cargo metadata` 找不到而启动失败。新增 `scripts/tauri.mjs` 包装，启动前把 cargo bin 前置进 PATH，再调用 tauri CLI（CI 走 rust-toolchain action 不受影响）
- **dsh 插件打包并发竞态**：`build:dsh-plugins` 增加互斥锁，避免 tauri dev 与手动构建并发执行时互相删除 vendor node_modules 导致 tarball 缺失
