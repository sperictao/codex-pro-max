# v1.1.0

DeepSeek Harness 远程访问上线后的首个功能版：集成页卡片化 + dsh 版本检查与一键更新。

## Features

- **dsh 版本检查与一键更新**：DeepSeek Harness 卡片显示当前版本胶囊；检测到 npm 有新版时出现「更新到 vX.Y.Z」按钮，一键 `npm install -g @deepseek-ai/dsh`，若 dsh web 正在运行会自动重启使其生效（语义版本比较支持 `0.1.0-rc.6` 这类 prerelease 版本，与 fastctx 共用 `version.rs`）
- **集成页卡片化**：FastCtx 与 DeepSeek Harness 分别装入独立卡片，DeepSeek Harness 置顶；卡片内含远程访问状态、安装进度时间轴、开机自启
- **dsh 远程访问（Tailscale）**：一键配置 Tailscale HTTPS 远程访问 dsh Web UI —— 安装 CLI → 启动 web（loopback:3899）→ 检查 Tailscale / MagicDNS → loopback 反代（:3898）→ serve 配置 → 真实 HTTPS 端点验证；失败节点内嵌问题与解决方案
- **Linux 自启兜底**：非 systemd 发行版（Alpine/Void/Devuan 等）回退 XDG autostart .desktop
- **README 友情链接**：新增 Linux.do 链接（中英文 README 同步）

## Fixes

- dsh 远程访问跨平台加固（Windows / Linux）：serve 步骤总是重跑幂等断言、verify 步骤改查真实 HTTPS 端点（避免配置存在但监听器未起的假成功）、macOS-only 代码 cfg 门控消除跨平台 dead_code 警告
- 看守配置测试通过 clippy 门禁（断言风格与 Default 初始化写法修正）

## 发布

- 版本号同步至 1.1.0（package.json / Cargo.toml / tauri.conf.json / Cargo.lock）
