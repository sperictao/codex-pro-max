# v0.2.3

修复自更新在 Windows / Linux 上检查更新失败（下载 404）的问题，发布产物文件名统一为 `dashi-taskboard-launcher`。

## Bug Fixes

- 修复 Windows / Linux 检查更新失败 `download request failed with status: 404`：GitHub 上传 release 资产时会把文件名中的空格替换为 `.`，latest.json 改用净化后的资产名生成下载地址
- 发布产物文件名统一为 `dashi-taskboard-launcher_*`（dmg / setup.exe / AppImage / deb / app.tar.gz），不再含空格，消除 GitHub 资产名净化导致的地址不一致
