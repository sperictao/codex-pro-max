# v0.2.0

重大更新：内置 dashi-taskboard、全新 Geist UI 主题、完整设置页面。

## Features

- **内置 dashi-taskboard**：将 dashi-taskboard 项目打包进应用，无需单独下载配置
  - 点击"使用内置"按钮自动填充路径
  - 打包后通过 Tauri resources 分发
- **全新 Geist 设计主题**：参考 one-publish 项目采用 Vercel Geist 设计系统
  - 纯白/纯黑底色，蓝色交互色
  - 亮色/暗色/跟随系统三种主题模式
  - 6px 圆角，微妙阴影，150ms Geist 缓动
  - 等宽字体用于技术信息
- **完整设置页面**：侧边栏导航 + 四个分类
  - 通用：Taskboard 路径（支持内置）、Node.js 路径、Codex 应用路径
  - 网络：主机地址、Taskboard 端口、CDP 调试端口
  - 模式：启动模式切换、自动打开浏览器、Skill 安装
  - 关于：版本号、更新源健康检查、检查更新、GitHub 链接

## Bug Fixes

- 修复 Windows 上初始化失败（HOME -> USERPROFILE）
- 修复 Windows 上进程终止使用 Unix kill 命令
- 修复 Windows 上浏览器打开命令缺失
- 修复 build-updater.mjs tauri 子命令重复
- 修复 Clippy 代码风格警告
