# v0.2.1

修复 v0.2.0 发布后发现的问题：Windows 控制台窗口闪烁、内置 taskboard 资源路径、Codex 应用检测。

## Bug Fixes

- 修复 Windows 上拉起 node / cmd / taskkill 时弹出控制台窗口（CREATE_NO_WINDOW）
- 修复打包后内置 taskboard 资源落点不一致：resources 改为显式映射 `../vendor/dashi-taskboard` → `vendor/dashi-taskboard`，并兼容两种历史落点
- 修复开发模式下找不到内置 taskboard：通过 CARGO_MANIFEST_DIR 回退到项目根 vendor 目录
- 修复 Codex 应用检测：指定路径为空时自动搜索常见安装位置（macOS / Windows / Linux）
- Unix 子进程使用独立进程组（process_group(0)），避免信号互相影响
