# v1.6.0

修复版：dsh web 停止链路修复与 DeepSeek Harness 卡片交互重构，本地/远程两种启动模式各自拥有匹配的安装进度时间轴。

## Features

- **dsh 卡片交互重构**：本地与远程访问入口统一为「一键启动 / 一键关闭 dsh web」按钮 + 「远程访问」开关。开关开启走完整远程访问链路（dsh web + Tailscale HTTPS Serve），关闭全停；本地按钮负责快速启停本地 dsh web 并自动打开浏览器。地址区只保留远程 HTTPS 地址，本地入口由一键启动按钮直接打开
- **本地模式安装进度**：一键启动本地 dsh web 现在与远程一键配置一样，按时间轴逐步推进（Node 检测 → 兼容 dsh 安装 → 启动 → 就绪），失败节点展示排查提示；就绪视图按本地 4 步而非远程 8 步渲染
- **远程模式安装进度**：远程一键配置时间轴保持 8 步（Node → dsh → 插件 → Tailscale → MagicDNS → 启动 → Serve → 验证），与本地模式在 UI 上明确区分

## Fixes

- **修复「停止 dsh web 无效」**：一键启动实际拉起的是 `dsh --profile web --host 127.0.0.1 --port 3899`（`--host` 插在 `profile web` 与 `--port 3899` 之间），而旧的进程匹配按连续子串 `"profile web --port 3899"` 永远命不中，导致停止按钮杀不掉进程、状态无法复位。统一改为 ERE 模式 `profile web.*--port 3899|--port 3899.*profile web`（兼容 npm 包布局与历史遗留进程），Windows 的 PowerShell 匹配路径同步修正；`dsh_web_pid` 的幂等识别也因同一问题会误判「端口被其他进程占用」，一并修复

## Changes

- 停止本地 dsh web / 关闭远程访问统一走全停链路；开关关闭即整条链路（dsh web + Serve）停止
- 新增工作台 Rust 侧本地启动步骤文案与前端「本地访问已就绪」双语资源；移除已废弃的按钮文案键
