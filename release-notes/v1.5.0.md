# v1.5.0

增强版：全应用日志记录完善（重点覆盖报错路径），dsh 集成卡片把本地与远程访问分开管理。

## Features

- **统一错误日志**：新增 Rust 侧日志工具（`logging.rs`），所有返回前端的错误路径统一落盘，杜绝「用户看到报错、日志文件里没有」的断层；覆盖 ProcessManager 进程事故、dsh 一键配置/启动/修复/开机自启、配置读写、FastCtx 集成、Codex 配置看守的全部失败分支
- **前端 IPC 日志**：所有 Tauri invoke 请求统一走带日志的包装层，IPC 失败自动记录命令名与错误；前端轮询与初始化静默失败路径补上日志（不新增任何 UI/告警，仍遵守「日志只进文件不进 UI」边界）
- **dsh 本地与远程拆分**：状态卡分别展示本地地址与远程 HTTPS 地址，各带「复制/打开」；停止动作拆分为「停止 dsh web」与「关闭远程访问」两个独立入口
- **授权插件状态判定优化**：dsh 状态卡不再把授权插件缺失排在本地运行之前——纯本地使用 dsh 不需要授权插件，未启用远程访问时不再误报「插件未安装」

## Changes

- dsh 一键配置慢速步骤（node 检测、兼容 dsh 安装）依旧按时间轴推进，失败节点在补日志的同时保留原排障提示
- 进程意外退出/启动失败在系统通知之外同步落盘日志文件（设置页「打开日志目录」可查）
- 前端统一日志带 `[codex-pro-max]` 前缀，便于 WebView console 过滤
