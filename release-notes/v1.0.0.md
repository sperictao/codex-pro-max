# v1.0.0

首个正式版：项目更名为 **Codex Pro Max**（原 **Dashi Taskboard Launcher**），定位与功能不变。

## Breaking Changes

- **产品改名**：应用显示名由 `Dashi Taskboard Launcher` 改为 `Codex Pro Max`（窗口标题 / 托盘 / 前端 header / 安装包名 / bundle identifier `com.codex.pro.max`）
- **仓库改名**：GitHub 仓库 `sperictao/dashi-taskboard-launcher` → `sperictao/codex-pro-max`；自更新端点与 README 链接已同步。已有克隆请更新远端：`git remote set-url origin https://github.com/sperictao/codex-pro-max.git`
- **配置目录迁移**：`~/.dashi-taskboard-launcher` → `~/.codex-pro-max`（config.json / codex-guard-schema.json / launcher-runtime.json）。已有配置请手动迁移：`mv ~/.dashi-taskboard-launcher ~/.codex-pro-max`

## Features

- **改名同步**：taskctl 的 launcher 运行时端点发现路径同步为 `~/.codex-pro-max/launcher-runtime.json`（vendor 子模块已同步，dbbff97）

## 发布

- 版本号同步至 1.0.0（package.json / Cargo.toml / tauri.conf.json）
- CI 产物名统一为 `codex-pro-max_<version>_*`
