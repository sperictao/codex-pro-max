# v0.1.2

修复 Windows 平台构建失败问题。

## Bug Fixes

- 修复 `build-updater.mjs` 在 Windows 上 `spawnSync npm ENOENT` 错误
  - Windows 上 `spawnSync("npm")` 找不到 `npm`，需要 `shell: true` 模式

## Features

- 一键启动/停止 Taskboard 服务和 Codex 注入器
- 实时状态监控（进程状态、PID、消息）
- 配置管理（Taskboard 路径、Node.js 路径、Codex 应用路径、端口、启动模式）
- Codex Skill 一键安装
- 独立窗口模式 / 完整启动模式切换
- Tauri v2 自动更新支持
- GitHub Actions 多平台构建发布（macOS aarch64/x86_64/universal、Windows、Linux）
