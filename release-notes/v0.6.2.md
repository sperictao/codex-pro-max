# v0.6.2

Windows 实机验证商店版 Codex 全链路（探测 → COM 激活 → CDP → 注入面板）首次跑通，并修复验证中发现的三个问题。

## Bug Fixes

- 修复注入器认不出 Windows 版 Codex 主页面导致注入静默失败：目标过滤命中 app:// 与 chatgpt.com 桌面页面，排除快捷聊天/浮层/听写路由（方案对齐 CodexPlusPlus）
- 修复 Codex 应用探测误报：名字含 codex 的第三方工具（如 Codex++）会被模糊匹配当成 Codex，并抢占商店版 MSIX 回退；安装目录/别名扫描改为 exe 精确名匹配（codex.exe / chatgpt.exe，忽略大小写）
- 修复安装包缺少 taskboard 页面静态资源：vendored taskboard 的 dist 未入库，此前全新安装注入的面板永远 404；release 构建现在先构建 vendored web UI 再打包
