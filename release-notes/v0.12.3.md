# v0.12.3

## Features

- **Codex 未开调试端口自动处理**：启动注入器检测到 Codex 已在运行但未开启 CDP 调试端口时，不再白白等待超时，而是弹窗提示——确认则自动关闭当前 Codex 并以调试参数重启，取消则终止本次启动（Windows 与 macOS 完整模式；macOS 独立窗口模式不受影响）
- **进程识别安全**：Windows 上按进程名+路径双重鉴别桌面版 Codex，避免误杀同名 Codex CLI 会话
- **自定义确认弹窗与加载过渡**：用应用内主题化弹窗替代原生系统对话框（随深浅色主题自动适配），重启期间显示加载层卡片，避免无反馈误以为卡死

## Fixes

- **一键启动幂等**：重启 Codex 的重试路径下，Taskboard 已运行时不再报「已在运行」中断注入器启动，改为直接复用继续

## Internals

- 新增 `quit_codex` 命令：先优雅退出（Windows WM_CLOSE / macOS osascript），限时未退出则强杀兜底
