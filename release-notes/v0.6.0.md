# v0.6.0

新增 Codex 配置看守：基于 schema 托管并锁定 `~/.codex/` 下的配置参数，锁定参数被改动时自动改回。

## New Features

- **配置看守总开关**：「设置 → 通用」开启后，顶部出现「看守」入口与参数自动检查
- **看守配置页**：按 config.toml / AGENTS.md / default.toml 分组展示托管参数，每条含推荐值、当前实际值、一致性状态；支持快捷修改、启用写入、锁定/解锁
- **锁定自动恢复**：锁定参数每 60 秒校验一次，发现漂移自动改回（仅应用运行期间），配置页显示上次校验/恢复时间
- **schema 驱动**：内置 11 条 v1 参数（multi_agent_v2 七键、image_generation、`[agents]` v1 块移除、AGENTS.md「子代理使用」段落、agents/default.toml）；schema 落盘 `~/.dashi-taskboard-launcher/codex-guard-schema.json`，可自行扩展参数
- **写入前备份**：任何写入（手动启用 + 自动恢复）前备份目标文件到 `~/.codex/dashi-backups/`，每文件保留 20 份

## Changes

- TOML 读写采用 toml_edit，保留 config.toml 中已有注释与格式；TOML 解析失败时暂停该组看守并报错，绝不重写整文件
- 解锁与全局关闭均不回滚已写入的值（边界决策见 docs/adr/0001）
