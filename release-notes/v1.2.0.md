# v1.2.0

功能版：内置 taskboard 升级（合并上游 origin/main 59 个提交），带来 AI 对话链、议题创建、Windows 原生 Taskboard 支持等。

## Features

- **内置 Taskboard 升级（v1.0.3 → 上游最新）**：合并 dashi-taskboard 上游 59 个提交，主要包括：
  - **AI 对话链**：从评论发起任务对话、通过 AI 对话导入项目任务、确认 Codex 项目后再创建线程；AI 对话模块按需加载（性能优化）、鉴权隔离、未读徽标只显示未读数
  - **创建议题与议题选择功能链**：创建议题、议题提及列表、关系菜单、跟随创建失败修复等
  - **看板列任务数量显示（LOCAL-202）** 与 **循环任务详情（LOCAL-206，含外部点击关闭弹层）**，移除议题操作成功 toast（LOCAL-204）
  - **Windows 原生 Taskboard 支持**：项目摘要进程树终止修复、Windows 桌面构建管线
  - 修复：外部 HTTP markdown 链接在系统浏览器打开、嵌入式链接拒绝非绝对路径、Codex 项目上下文实时读取、新对话保留任务标题等

## Changes

- **fork 侧适配保留**：taskctl 运行时端点发现（`~/.codex-pro-max/launcher-runtime.json`）与 Windows Codex 注入器修复在合并中完整保留
- **打包适配**：上游新增运行时文件 `shared/process-tree.mjs`、`shared/executable-command.mjs` 均在既有打包白名单（`shared/`）内，打包资源无需调整

## 发布

- 版本号同步至 1.2.0（package.json / Cargo.toml / tauri.conf.json / Cargo.lock）
- 内置 taskboard 指针更新至 `e32620b`
