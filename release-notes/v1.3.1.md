# v1.3.1

修复版：内置 taskboard 插件入口与注入目标识别跟随 Codex 桌面端最近的界面/页面调整。

## Fixes

- **插件入口回退语义导航**：Codex 侧栏的 `[data-app-action-sidebar-scroll]` 数据钩子在部分版本消失，导致 taskboard 注入脚本找不到「插件」行、入口按钮无法克隆。现回退到 `aside nav[role="navigation"]` 语义导航继续查找；命中原生 Plugins 行后不再要求至少 3 个兄弟按钮，直接克隆注入
- **注入目标排除 avatar composition surface**：Codex 新增 `avatar-overlay-composition-surface.html` 页面（标题含 Codex、`app://` 协议），会被注入器误判为 Codex 主页面抢先注入。现按页面路径显式排除，确保注入只发生在真正的主页面上

## 验证

- 内置 taskboard 相关测试 `codex-targets-filter` / `inject` 共 29 例全绿（含新增「sidebar data hook 消失后语义导航命中」与「composition surface 不得抢注」用例）
- 启动器 `tsc --noEmit` / `vitest run` / `vite build` 通过
- taskboard web 资源重新构建，产物随 launcher 资源打包

## 发布

- 版本号同步至 1.3.1（package.json / Cargo.toml / tauri.conf.json / Cargo.lock）
- 内置 taskboard 指针更新至 `79bbd5a`
