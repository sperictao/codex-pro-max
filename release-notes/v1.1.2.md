# v1.1.2

修复版：dsh web 首次启动超时（一键启动第一次失败、第二次成功）与打开按钮位置微调。

## Fixes

- **dsh web 首启超时**：首次启动 dsh web 需要初始化（Windows 上还包括杀软对新装 dsh 包依赖的实时扫描），可能超过原来的 20 秒等待导致一键启动失败，重试才成功。修复：
  - 启动等待放宽到 60 秒，并轮询子进程存活——进程已死立即报错（不干等超时），进程活着继续等到就绪（新增 `libc` 依赖做 Unix 侧 `kill(pid,0)` 探活；Windows 用 `OpenProcess` + 退出码）
  - 超时/崩溃时把 `~/.dsh/dsh-web.log` 尾部真实错误（崩溃堆栈）直接展示在时间轴「问题」区（多行渲染），不再只给一句通用提示
  - 针对 Windows 最常见的首启崩溃（创建符号链接被拒 EPERM），给出「开启开发者模式后重试」的针对性方案

## Features（布局调整）

- **打开按钮移至 URL 胶囊右侧**：操作行右侧顺序为 URL 胶囊 → 打开按钮

## 发布
