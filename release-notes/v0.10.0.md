# v0.10.0

## Features

- 主题系统从 daisyUI 迁移至 tweakcn（shadcn token）体系：内置 42 个主题族（Vercel、Claude、Catppuccin、Supabase、Graphite 等），全部原生支持亮 / 暗 / 跟随系统，默认族为 Vercel；升级后旧主题选择自动回落到默认族
- 主题字体随族切换：28 种界面字体（latin / latin-ext 子集）全部应用内自托管，完全离线可用，CSP 保持不变
- 外观设置页调整：模式卡移至主题族网格上方；模式卡预览改为放大的迷你 UI 骨架（标题条 / 文本行 / 主按钮，120×72）

## Internals

- 新增 `scripts/build-themes.mjs`：从 tweakcn registry 一键再生成主题 token、族清单与本地字体（ADR 0008）
- 移除 daisyUI 与 Geist 字体包依赖；组件样式全部改写为 Tailwind utility + 语义 token
