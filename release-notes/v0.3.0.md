# v0.3.0

系统托盘支持、外观设置页、Skill 独立页面与安装状态检测。

## New Features

- 系统托盘：托盘菜单提供显示主窗口、一键启动、全部停止、退出，左键点击托盘图标显示窗口；托盘启动/停止与界面按钮共用同一套逻辑，窗口打开时状态实时同步
- 关闭窗口时最小化到托盘："设置 → 通用 → 系统行为"新增开关，开启后点击关闭按钮隐藏窗口驻留托盘（macOS 连 Dock 图标一起隐藏），子进程继续运行；默认关闭，保持原有退出行为
- 外观设置页：设置侧栏新增"外观"，主题切换改为预览卡片（跟随系统/亮色/暗色，纯 CSS 迷你窗口预览图 + 选中徽章），即点即生效
- Skill 独立页面：安装 Skill 从"设置 → 模式"独立为头部 Skill 按钮直达的专属页面，含功能说明与安装动作
- Skill 安装状态检测：Skill 页顶部实时显示安装状态徽章（已安装/未安装/安装异常），符号链接指向与当前 Taskboard 路径不一致时给出提示；打开页面与安装完成后自动刷新

## Changes

- 设置侧栏各项增加图标（通用/外观/网络/模式/关于）
