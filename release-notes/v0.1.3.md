# v0.1.3

修复 Windows 平台兼容性问题。

## Bug Fixes

- 修复 Windows 上初始化失败：`HOME` 环境变量不存在，改用 `USERPROFILE`
- 修复 Windows 上 `install_skill` 无法创建符号链接（使用 `symlink_dir`/`symlink_file`）
- 修复 Windows 上 `open_taskboard` 无法打开浏览器（改用 `cmd /c start`）
- 修复 Windows 上进程终止使用 Unix-only 的 `kill` 命令（改用 `taskkill`）
- 修复 `default_codex_path` 在 Windows/Linux 上返回 macOS 路径

## Features

- 一键启动/停止 Taskboard 服务和 Codex 注入器
- 实时状态监控（进程状态、PID、消息）
- 配置管理（Taskboard 路径、Node.js 路径、Codex 应用路径、端口、启动模式）
- Codex Skill 一键安装
- 独立窗口模式 / 完整启动模式切换
- Tauri v2 自动更新支持
- GitHub Actions 多平台构建发布（macOS aarch64/x86_64/universal、Windows、Linux）
