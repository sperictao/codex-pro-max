# v1.9.0

DeepSeek Harness（dsh）访问模式体验优化：默认本地访问模式，并记住用户切换的选择。

## Features

- **访问模式默认本地**：进入应用默认本地访问模式（`http://127.0.0.1:3899`），远程访问（Tailscale HTTPS）需用户显式切换
- **记住用户的模式选择**：切换本地 / 远程访问模式后写入本地存储，应用重启后沿用上次的选择，不再每次回到默认
