# v0.11.0

## Features

- 看守参数卡交互重构：参数说明与配置路径收进参数名旁的 ? 悬浮卡片，卡片更紧凑
- 「启用」改为带状态文字的开关胶囊（已启用 / 已禁用），弹性滑动动效；「锁定 / 解锁」改为图标 + 文字按钮
- 操作区收进参数卡右栏（30% 宽，窄卡自动换行），平时隐藏、悬停卡片时淡入，键盘聚焦同样可见
- 新增「禁用」：仅停止看守，不回滚已写入 ~/.codex/ 的值（与删除参数的语义一致）；锁定状态下需先解锁
- fastctx 未安装时可在设置页一键 npm 全局安装
- 看守页内容不再限宽，随窗口自适应

## Internals

- 新增通用 `text-switch` 控件：宽度走 CSS 变量、旋钮位移 calc 自动跟随，任意位置可复用
- 新增后端命令 `guard_set_applied` 与 `fastctx_install`；fastctx CLI 调用抽象为通用 `cli_command`（Windows 经 cmd /c 执行批处理）
