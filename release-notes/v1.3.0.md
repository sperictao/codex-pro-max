# v1.3.0

技术版：壳前端整体迁移 React（保行为重写），并带来更新入口与状态展示的体验升级。

## Features

- **头部更新入口**：检测到更新时，软件名右侧出现圆形箭头按钮，点击即装；下载中按钮边框转为进度环（12 点顺时针填充），箭头切换为百分比数值
- **关于页更新状态卡**：源健康徽标、当前 → 最新版本对比、release notes、上次检查时间与失败原因持久展示（不再只靠瞬态 toast）
- **软件名点击直达 GitHub 仓库**；关于页 GitHub 链接修正为本仓库地址（原为 github.com 占位符）

## Changes

- **壳前端 vanilla TS → React 19 保行为重写**（ADR-0010，取代 ADR-0009）：约 2200 行命令式 DOM 重构为 `features/` + `shared/` 组件结构；Zustand 状态、react-i18next（字典原样沿用）、集中式类型化 IPC 模块（命令/事件名全仓唯一）；行为逐条冻结——41 族主题、双语、原生确认弹窗、托盘、窗口记忆、事件推送全部不变
- **前端首次引入测试基建**：Vitest + Testing Library 覆盖看守域锁定状态机与四 apply_mode 交互（12 例），CI 质量门新增 `vitest run`
- **浏览器冒烟 harness**：`pnpm smoke`——headless Chromium + Tauri IPC Mock，100 项断言覆盖全部视图与事件桥，无需启动真实应用
- 修复：dev 环境双 React 实例白屏（vite 依赖预打包误扫 vendor 入口，现显式限定 `optimizeDeps.entries`；生产构建不受影响）

## 验证

- `tsc --noEmit` / `vitest run`（12 例）/ `vite build` 全绿
- 浏览器冒烟 100/100（含 20+ 张截图逐张目检、控制台零错误）
- 真实应用启动级验证：窗口创建、window-state 落盘、日志零错误、单实例拦截与优雅退出均实测正常

## 发布

- 版本号同步至 1.3.0（package.json / Cargo.toml / tauri.conf.json / Cargo.lock）
- 内置 taskboard 指针不变
