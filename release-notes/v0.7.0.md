# v0.7.0

Taskboard 改为 git submodule 集成、与主仓库解耦各自更新；配置看守新增自定义参数与看守文件管理。

## New Features

- 配置看守支持自定义托管参数：UI 内增删（id 以 `custom.` 开头），含目标文件、路径、apply_mode 全要素校验
- 看守文件列表可管理：内置 config.toml / AGENTS.md / agents/default.toml 之外可增删自定义文件，首次进入自动探测实际路径，路径不一致时弹窗确认后才更新配置
- 设置保存统一走 update_settings，看守启用/锁定状态不再被回滚

## Improvements

- dashi-taskboard 从 vendored 文件拷贝改为 git submodule（指向 fork、pin commit），两个仓库各自独立更新，launcher 发版时显式 bump；注入器修复已上游化（chuspeeism/dashi-taskboard PR #28）
- 安装包瘦身：打包改为运行时白名单（server/shared/scripts/inject/dist/web），不再把 web 源码、测试、proof 图片和本地运行时数据打进安装包
