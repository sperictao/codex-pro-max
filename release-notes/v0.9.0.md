# v0.9.0

## New Features

- **界面多语言（English / 中文）**：通用设置顶部新增语言卡片（跟随系统 / English / 中文），切换即时生效、无需重启；「跟随系统」按 OS 语言解析，中文系统显示中文，其余默认英文
- 覆盖启动器壳全部界面文本与 Rust 侧字符串：托盘菜单、进程状态、更新提示、错误消息
- 看守页托管参数双语化：内置参数的 label/description 提供英文；「Subagent Usage」段落与 default subagent definition 的**写入内容**同样双语——英文界面下 AGENTS.md 段落与 agents/default.toml 指令写入英文版

## Behavior Changes

- 带 `default_en` 的看守参数，其期望值随界面语言：切换语言后未锁参数显示漂移（由用户决定重应用），已锁参数在 60 秒轮询内自动恢复为新语言内容；用户改过的值永远优先
- 内置 schema 的英文资源（`label_en` / `description_en` / `default_en`）始终以内置版本为准，旧磁盘副本无需迁移

## Notes

- 技术方案见 `docs/adr/0004-dual-i18n-mechanism.md`：前端 i18next（英文原文作 key）+ Rust 侧极简字典，同一套「英文即源文、缺失落回英文」语义
