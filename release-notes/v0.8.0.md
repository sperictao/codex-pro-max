# v0.8.0

设置页新增「集成」区：一键接入/摘除 FastCtx（MCP 仓库工具集），接入与配置写入全程委托 fastctx 官方 CLI。

## New Features

- 设置页新增「集成」区，FastCtx 开关：接入 = `fastctx apply`（默认 Standard 输出档），摘除 = `fastctx unapply`（删除 ~/.fastctx 受管数据，npm 包保留，可随时重新接入）
- 安装检测与接入状态实时显示：PATH 探测 fastctx 可执行性 + 版本号；接入状态以 `~/.codex/config.toml` 的 `[mcp_servers.fastctx]` 为唯一事实来源，不存开关布尔值、无漂移
- 未安装时给出 `npm install --global fastctx` 引导；接入成功后自动跑 `fastctx status` 自检，未通过仅警告不回滚；摘除前弹窗确认
- 「打开 fastctx 控制台」按钮：输出档位、后台任务、更新等管理全部导流给 fastctx 官方 TUI

## Notes

- 启动器不写任何 fastctx 拥有的 TOML 键（`mcp_servers.fastctx`、`tool_output_token_limit`、`features.code_mode.*`），一律委托 CLI，决策见 ADR 0003；这些键不建议加入配置看守
- 接入/摘除后需重启 Codex 会话生效；fastctx apply 会连带配置 ChatGPT 桌面端（其官方行为）
- README 新增第三方声明区（dashi-taskboard、FastCtx）
