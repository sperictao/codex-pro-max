# v1.3.2

修复版：Codex 退出后主页注入器状态卡如实报错，并补上 dsh 远程访问的排障入口与复制地址操作。

## Fixes

- **Codex 停止后注入器不再永远显示「运行中」**：注入器 `--watch` 进程在 Codex 退出后不会自己退出，而是继续等待重连，旧逻辑只看子进程存活，主页状态卡一直显示 Running。现在启动器会同时检测注入器依赖的 Codex CDP 端口：端口失联即优雅终止注入器，状态置为 Failed，消息为「Codex 已退出，注入器失去 CDP 端口 {port}」（英文 UI 对应 "Codex exited; injector lost CDP port {port}"）

## Changes

- **dsh 远程访问排障**：
  - 集成页 dsh 卡片新增「复制地址」按钮（Open 只能系统浏览器打开，用户想发到手机或换已配好代理规则的浏览器时需要手动复制）
  - 远程地址可用时展示排障提示：`*.ts.net` 打不开多半是访问端代理工具（Shadowrocket / Clash / Surge）拦截，附「排障指南」链接
  - 新增 `docs/dsh-remote-access.md`：根因、自查步骤、各代理工具 DIRECT 规则配置，并强调不要为了绕过代理而把管理面暴露到公网
  - README 双语同步该提示与指南入口
- **壳页面允许文本选择**：`index.html` / `smoke.html` 移除 body 级 `select-none`，日志、地址等文本可选中复制
