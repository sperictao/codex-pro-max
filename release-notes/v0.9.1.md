# v0.9.1

## New Features

- **登录时启动（Autostart）**：通用设置新增开关，启用后登录系统时静默启动并驻留系统托盘；开关状态以 OS 注册项为准，不存配置
- **窗口状态记忆**：主窗口尺寸/位置/最大化在重启后恢复；恢复位置落在已拔掉显示器上时自动改回居中
- **单实例**：重复启动不再新开实例，转为激活已有实例并显示主窗口（防止看守轮询双写 codex 文件、taskboard 端口冲突）
- **进程事故系统通知**：taskboard / 注入器意外退出或启动失败时弹系统通知（漂移恢复与更新流程保持静默）
- **壳日志**：Rust 侧日志落盘（单文件上限 2MB，超限轮转仅保留当前一份），通用设置新增「打开日志目录」入口；panic 信息同步落盘

## Security

- 启用 CSP（`default-src 'self'` + 按需放行 inline/dev）
- shell 插件权限收窄为仅 `open`；其 `open` 作用域配置为精确 regex（http(s) URL / POSIX 绝对路径 / Windows 盘符路径）
- 移除前端零调用的 fs 插件（Cargo/npm 依赖与 capability 同步移除）

## Fixes

- 修复 shell `open` 打开本地路径被默认作用域拦截报错（影响「打开日志目录」「打开 codex 目录」与 updater 帮助路径）

## Notes

- 决策记录见 `docs/adr/0005-single-instance.md` 与 `docs/adr/0006-shell-notification-scope.md`；术语与语义边界见 `CONTEXT.md`「启动器壳（Shell）」
- 已知限制：macOS 登录项不支持启动参数，mac 自启时会显示主窗口而非静默到托盘
