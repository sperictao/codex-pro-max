# v0.2.4

修复一键启动时 taskboard 服务报错 `启动失败: no such file or directory (os error 2)` 的问题，配置目录更名为 `~/.codex-pro-max`。

## Bug Fixes

- 修复一键启动失败 `no such file or directory (os error 2)`：从 Finder / 桌面图标启动时系统 PATH 不含 node 安装目录，空配置下自动探测 `/opt/homebrew/bin`、`/usr/local/bin`、`~/.local/bin` 等常见 node 位置，探测失败再退回 PATH 查找
- Node.js 路径解析逻辑统一：`check_node_version`、`run_taskctl`、服务/注入器启动共用同一解析函数

## Changes

- 配置目录由 `~/.dashi-launcher` 更名为 `~/.codex-pro-max`，已有配置请手动迁移：`mv ~/.dashi-launcher/config.json ~/.codex-pro-max/`
