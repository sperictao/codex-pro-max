# v0.4.0

应用更新功能重构：后端接管更新流程，支持下载进度、自动重试与安装后自动重启。

## New Features

- 启动自动检查更新：应用启动后静默检查，发现新版本时提示并在"设置 → 关于"展示版本号与更新日志
- 更新下载进度：下载/重试/安装阶段实时显示进度条与百分比，网络异常自动重试最多 3 次（指数退避）
- 安装后自动重启：更新安装完成自动停止子进程并重启应用，无需手动操作
- 更新源配置帮助：更新源未配置时，"关于"页提供配置指南与配置模板一键打开

## Changes

- 更新检查与安装迁移到 Rust 后端，更新对象缓存避免重复请求更新源；缓存包损坏时自动拉取新包重试
- 更新检查 20 秒、下载 15 分钟超时，错误信息给出可行动的中文提示
- "关闭窗口时最小化到托盘"开关移至右侧
- 默认启动模式调整为完整启动模式（重启 Codex）；已有配置不受影响
