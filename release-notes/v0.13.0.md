# v0.13.0

## Features

- **内嵌 Taskboard 升级到 v0.2.3（298 个提交）**：跟随 dashi-taskboard 上游演进，含面板多语言（跟随 Codex 语言）、markdown 图片编辑、附件上传、甘特图/看板暗色适配、更新检查等大量功能与修复

## Changes

- **Taskboard 独立打开页面带安全前缀**：配合上游 v0.2.3 的 instance token 机制，「打开面板」与 taskctl 命令现在通过带 token 的地址访问服务，旧的无前缀根路径已不再可用

## Internals

- **接入 Taskboard v0.2.3 instance token 认证**：server 与 injector 现在由启动器生成并注入一致的 token/secret（持久化于本机配置，跨重启稳定）；健康检查改为带 challenge 的 HMAC-SHA256 proof 校验，与上游算法一致（新增回归单测）
- **升级须知（安装/升级后首次使用）**：旧版 Taskboard 服务进程与新版不兼容，请停止旧服务后重新一键启动；升级后设置页需确认 Taskboard 路径仍指向内嵌资源（或重新「使用内置 Taskboard」）
